## Constants

`PALETTE` is the list of colours the plotters cycle through, `COLOURS` gives the colour for a named role
(`correct`, `error`, `no_response`, `mean_line`, `sem_fill`, `default`), and `UM_CMAP` is the colour map for
update matrices.
