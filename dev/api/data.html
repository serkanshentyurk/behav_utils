behav_utils.data#

behav_utils.data — data structures, loading, selection, filtering and synthetic data.

Hierarchical containers, config-driven loading, session selection, trial-level filtering, and synthetic generation.

Pipeline:

load_experiment(config)                            → ExperimentData (reader → build_session)
select_sessions(animal, preset='expert')           → List[SessionData]
filter_trials(sessions, trial_type='non_opto')     → List[SessionData]
TrialArrays.from_sessions(clean)                   → TrialArrays (pool_arrays underneath)

One row per session — a tabular view for building selection masks.

Convenience for picking sessions (not trials). Mask against it like any DataFrame, for example t[t.session_type == 'opto'] for the sessions with laser trials.

class behav_utils.data.TrialArrays(choice, stimulus, category, prev_choice=None, prev_stimulus=None, prev_category=None, reaction_time=None, trial_key=None, correct=None, prev_correct=None, task=None, truth=None)[source]#

Aligned per-trial arrays for one block of (pre-filtered) trials.

All fields are 1-D float arrays of equal length. choice is NaN on no-response trials; prev_* are NaN where there is no usable predecessor. trial_key (int64, or None) identifies each row across resampling.

correct and prev_correct are the task’s score: 1.0 correct, 0.0 error, NaN where the task gives none (no response, abort, unscored). task is the Task that scored them; every statistic reads correctness from here, never from choice == category. Built without a score (by hand), both are derived from the task (TwoAFC() unless given). truth is the task’s correct response per trial (the category in 2-AFC, the stimulus in reproduction), so error statistics never recompute it.

Variables:

  • choice (numpy.ndarray) – The response in category space; NaN on no-response trials.

  • stimulus (numpy.ndarray) – The stimulus on the library’s axis.

  • category (numpy.ndarray) – The task’s category for the stimulus.

  • prev_choice (numpy.ndarray) – The previous trial’s choice; NaN where there is no usable predecessor.

  • prev_stimulus (numpy.ndarray) – The previous trial’s stimulus, likewise.

  • prev_category (numpy.ndarray) – The previous trial’s category, likewise.

  • reaction_time (numpy.ndarray) – Response latency in seconds.

  • trial_key (numpy.ndarray | None) – The row’s identity across resampling (int64), or None.

  • correct (numpy.ndarray | None) – The task’s score: 1.0 correct, 0.0 error, NaN where the task gives none.

  • prev_correct (numpy.ndarray | None) – The previous trial’s score, likewise.

  • task (behav_utils.tasks.base.Task | None) – The Task that scored the trials.

  • truth (numpy.ndarray | None) – The task’s correct response per trial.

classmethod from_sequence(choice, stimulus, category=None, reaction_time=None, *, task=None)[source]#

From one contiguous block with no carried lag-1 view.

The task (TwoAFC() unless given) decides the categories and scores the trials, exactly as on loading: a go/no-go blank is read as a withhold. category, if given, is only checked against the task’s.

The predecessor of trial t is trial t-1 by adjacency, with no predecessor at t = 0. A no-response predecessor carries its NaN choice through (so has_prev is False there) while its stimulus and category are still recorded — the same rule the loader applies when it freezes the lag-1 view on a raw session, so this matches from_sessions exactly on one abort-free block.

behav_utils.data.load_experiment(config_or_path, *, reader=None, strict=True, sessions=None)[source]#

Load every session a reader finds, or the chosen sessions, into an ExperimentData.

Sessions in sessions_to_ignore are dropped before their tables are read. Animal metadata comes from animal_metadata (or animal_metadata.json in the csv_folders data directory); then session_types are stamped and session_presets registered.

Parameters:

  • config_or_path (ProjectConfig | str | Path) – A ProjectConfig, or the path of a YAML config.

  • reader (Callable[[...], Iterable[RawSession]] | None) – Where the trial tables come from; by default the reader the config’s reader: block names. Any callable that takes the config and yields RawSession objects works, and one that accepts a strict keyword is given this function’s.

  • strict (bool) – Raise on the first session that fails to load (the default); False logs it and skips it.

  • sessions (DataFrame | Iterable[str] | None) – Only these sessions: a table with a session_id column (discover_sessions, filtered) or session ids. The others are never read, and sessions_to_ignore still applies.

Returns:

The experiment, its animals sorted by id and each animal’s sessions in chronological order.

Raises:

  • FileNotFoundError – The config file, or the animal_metadata file it names, does not exist.

  • ConfigError – The config cannot be used as written.

  • RuntimeError – With strict, a session failed to load; the message names it and the reason.

  • ValueError – A sessions table has no session_id column, or, with strict, the reader does not find a requested session.

Warns:

UserWarning – Without strict, the reader does not find a requested session. Also, once per value, a session type read from a column that is neither derived nor listed in session_types, which is usually a typo.

Return type:

ExperimentData

behav_utils.data.build_session(raw, config, *, strict=True, session_idx=0, source_id=None)[source]#

One raw session → SessionData: the half of loading that every reader shares.

Checks the required columns, reads session metadata from the first row, maps and coerces the trial columns, normalises the stimulus, converts the choice and derives the category, correctness and session type. The animal id is the reader’s; a mapped animal_id column that disagrees raises (strict) or warns and is overwritten. Trial numbers must be unique (repeats raise, or with strict=False warn and are renumbered from 1) and lie in 0..1,048,575, the trial key’s range. AnimalData sets session_idx; the loader passes the canonical session id in raw and the reader’s own name as source_id.

Raises:

ValueError – no date, no trials, a missing required column, or (strict) an animal-id mismatch.

Parameters:

  • strict (bool)

Three ways to call it: a preset alone (select_sessions(animal, 'expert')), a preset with fields overridden (select_sessions(animal, 'expert', min_accuracy=0.80)), or fields alone (select_sessions(animal, stage='task', last_n=5)).

A preset is resolved on the animal’s own config (session_presets of the experiment it was loaded with) before the process-wide registry, so two experiments loaded in one session never see each other’s presets.

Parameters:

  • animal (AnimalData) – The animal to select from.

  • preset (str | None) – The name of a preset, from the animal’s config (session_presets) or registered with register_preset; None for criteria alone.

  • **overrides (Any) – SessionFilter fields, on their own or overriding the preset’s.

Returns:

The matching sessions, in chronological order; possibly none.

Raises:

  • KeyError – preset is neither in the animal’s config nor registered.

  • TypeError – An override is not a SessionFilter field.

class behav_utils.data.SessionFilter(stage=None, distribution=None, session_type=None, min_accuracy=None, max_accuracy=None, last_fraction=None, first_n=None, last_n=None, last_n_qualifying=None, after_session_idx=None, before_session_idx=None, session_indices=None, min_trials=10, exclude_opto=False, exclude_types=(), custom_filter=None)[source]#

Immutable session selection criteria.

Every field is optional; None means no constraint. select_sessions applies them in this order, each step narrowing the previous: metadata (stage, distribution); session type (session_type, or else the exclusions exclude_opto and exclude_types); index range (after_session_idx, before_session_idx, session_indices); position (last_fraction, first_n, last_n); quality (min_accuracy, max_accuracy, min_trials); last_n_qualifying; and custom_filter. Which sessions count is settled before any position is taken, so last_n=5 with exclude_types=('sham',) gives the last five sessions that are not sham.

Variables:

  • stage (str | List[str] | None) – Task stage (exact match, or list for OR-logic)

  • distribution (str | List[str] | None) – Stimulus distribution (exact match, or list for OR-logic)

  • session_type (str | List[str] | None) – Session type — ‘regular’, ‘opto’, or any project type stamped from config.session_types (e.g. ‘sham’). Accepts a string or list. When set, exclude_opto and exclude_types are ignored (the caller is explicitly choosing which types to include).

  • min_accuracy (float | None) – Minimum session accuracy (fraction correct)

  • max_accuracy (float | None) – Maximum session accuracy

  • last_fraction (float | None) – Keep only the last X fraction of sessions (applied BEFORE accuracy filtering)

  • first_n (int | None) – Keep only the first N sessions (after the metadata, session-type and exclusion filters)

  • last_n (int | None) – Keep only the last N sessions (likewise)

  • last_n_qualifying (int | None) – Keep only the last N sessions that pass the quality filters (applied AFTER min_accuracy / max_accuracy / min_trials, unlike last_n which is applied before them)

  • after_session_idx (int | None) – Only sessions with session_idx > this value

  • before_session_idx (int | None) – Only sessions with session_idx < this value

  • session_indices (List[int] | None) – Explicit list of session_idx values to include

  • min_trials (int) – Minimum valid (non-abort, responded) trials

  • exclude_opto (bool) – If True, exclude sessions with opto trials (ignored when session_type is set). Applied before the positional steps.

  • exclude_types (Tuple[str, ...]) – Session types to drop when session_type is not set, e.g. (‘sham’, ‘washout’). The names are the project’s; the library derives only ‘regular’ and ‘opto’ from the data. Applied before the positional steps.

  • custom_filter (Callable | None) – Callable(SessionData) -> bool for arbitrary filtering

behav_utils.data.filter_trials(sessions, mask_fn=None, min_trials=10, label='', exclude_abort=True, exclude_opto=True, trial_type=None)[source]#

Filter trials within each session. Returns new SessionData objects.

Each session is filtered independently and rebuilt via filter_session; sessions with fewer than min_trials surviving trials are dropped. Aborts are always dropped by trial_type; no-response trials are kept (their choice is NaN and every statistic ignores them).

Three ways to say which trials, in order of preference:

  1. trial_type, the named selections (use this):

    • 'all': every non-abort trial, opto included

    • 'non_opto': non-abort, laser-off trials

    • 'opto': laser-on trials only

    • 'post_opto': the first laser-off trial after each opto run

  2. mask_fn, a session -> bool mask for anything else (exclude_abort and exclude_opto are then ignored).

  3. Neither: build_mask with exclude_abort / exclude_opto (equivalent to trial_type='non_opto' by default).

trial_type and mask_fn are exclusive; passing both raises. Filtering trials in the data-structures reference shows these calls on synthetic data.

Parameters:

  • sessions (List[SessionData]) – List of SessionData.

  • mask_fn (Callable | None) – Callable: session -> boolean mask (length n_trials).

  • min_trials (int) – Drop sessions below this surviving-trial count.

  • label (str) – Human-readable description (auto-generated if empty).

  • exclude_abort (bool) – (no mask_fn / trial_type only) drop aborted trials.

  • exclude_opto (bool) – (no mask_fn / trial_type only) drop laser-on trials.

  • trial_type (Literal['all', 'non_opto', 'opto', 'post_opto'] | None) – One of the named selections above.

Returns:

List of new SessionData with filter_info set.

Raises:

ValueError – unknown trial_type, or both trial_type and mask_fn given.

Return type:

List[SessionData]

behav_utils.data.opto_mask(trials, delta=0)[source]#

Boolean mask for trials at a fixed offset from opto events.

Aborted trials are excluded from all masks (they are invalid data). Consecutive opto trials are treated as one “run” — offsets are measured from run boundaries, not individual trials within a run.

    Which trials, as an offset from each opto run:

    • 0: opto trials

    • 1: the first non-abort, non-opto trial after each opto run

    • 2: the second non-abort, non-opto trial after each opto run

    • -1: the last non-abort, non-opto trial before each opto run

    • 'control': all non-abort, non-opto trials; adjacency to an opto run is NOT considered, so combine with delta=±k masks to exclude neighbours
