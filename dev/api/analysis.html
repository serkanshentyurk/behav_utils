behav_utils.analysis#

behav_utils.analysis — phase-level statistics, contrasts, resampling, group tests.

compute_phase_stats gives the statistics of one phase, pooled or per session; compute_delta_stat contrasts phases with bootstrap and permutation uncertainty; compute_interaction takes the difference of two contrasts; and the group functions test per-animal values across animals.

Scalar statistics live in behav_utils.stats; array-valued readouts and the two fit engines on raw arrays (fit_psychometric, fit_update_matrix) in behav_utils.readouts.

Files: phase.py (compute_phase_stats), comparison.py (contrasts), resampling.py (the draw engine and draw summaries), group.py (across-animal tests), rolling.py.

behav_utils.analysis.compute_delta_stat(phases, names=('mu', 'sigma', 'lapse_low', 'lapse_high'), *, labels=None, reference=None, curve=True, update_matrix=False, downsample=False, n_permutations=0, n_bootstrap=1000, units=('trials',), n_bins=8, trial_filter='post_correct', n_repeats=200, seed=42)[source]#

Compare N phases against a reference, with bootstrap CI and permutation p.

Parameters:

  • phases (Mapping[str, Sequence[SessionData]] | Sequence[Sequence[SessionData]]) – {label: phase}, or a list of phases with labels. Each phase is the output of filter_trials.

  • names (Sequence[str]) – scalar stat names (default: the four psychometric params).

  • labels (Sequence[str] | None) – The phase labels, in order, when phases is a list; None for ‘phase_0’, ‘phase_1’, and so on. Ignored when phases is a dict.

  • reference (str | None) – label the others are contrasted against (default: first).

  • curve (bool) – also fit a PsychometricCurve per phase (display).

  • update_matrix (bool) – also fit an UpdateMatrix per phase and report the matrix difference, RMSE and correlation per contrast (descriptive only — no resampling; one matrix is nine fits).

  • downsample (bool) – match trial counts across phases before comparing (matched n per unit: trials for stats and the curve, post-correct pairs for the matrix). Removes precision bias at the cost of power.

  • n_permutations (int) – label shuffles for a permutation p (default 0 = none). Valid only when the label was randomised per trial, so every non-reference phase must share at least one session with the reference (same session_id) and none may share a trial with it, or a ValueError is raised. Floor is 1 / (n_permutations + 1).

  • n_bootstrap (int) – resamples per phase per unit (0 to skip).

  • units (Sequence[str]) – resampling units, e.g. ('trials', 'sessions'). The first is the default for .boot() / .table(). A phase with < 2 sessions gets no session draws.

  • n_bins (int) – Stimulus bins of the update matrices.

  • trial_filter (str) – Which pairs the update matrices use, ‘post_correct’ or ‘all’.

  • n_repeats (int) – matched-n draws for the readouts when downsampling.

  • seed (int) – base RNG seed.

Returns:

DeltaStats.

Raises:

ValueError – fewer than two phases, unknown reference or unit, an order-dependent stat requested with trial-level resampling, or a permutation requested between phases that share no session or that share trials.

Warns:

UserWarning – a phase shares trials with the reference (no permutation requested). One trial class containing another, e.g. post_opto inside non_opto, dilutes the contrast; make the reference disjoint with a mask_fn.

Return type:

DeltaStats

behav_utils.analysis.compute_interaction(result_a, result_b, contrast, *, contrast_b=None, label_a='a', label_b='b')[source]#

Difference of differences between two DeltaStats results.

Answers “is the opto effect different in these sessions than in those” — e.g. whether the on − off shift on sham sessions differs from the shift on real opto sessions, which is what separates an inactivation effect from the light-delivery artefact. Comparing two p-values is not a substitute: “significant here, not there” is not evidence they differ.

Bootstrap only: session type was not randomised per trial, so no shuffle reproduces the design.

Parameters:

  • result_a (DeltaStats) – The first output of compute_delta_stat.

  • result_b (DeltaStats) – The second. Pass the same object twice to compare two contrasts within one result; their shared reference draws then cancel exactly.

  • contrast (str) – contrast key in result_a, e.g. ‘opto_vs_non_opto’.

  • contrast_b (str | None) – contrast key in result_b; defaults to contrast.

  • label_a (str) – The first result’s name in the output.

  • label_b (str) – The second result’s name in the output.

Returns:

An Interaction, the difference between the two contrasts per statistic, with its bootstrap uncertainty.

Raises:

  • KeyError – if either contrast is absent.

  • ValueError – if the two contrasts share no bootstrap unit.

Return type:

Interaction

behav_utils.analysis.bootstrap_phase_stats(phase, names, *, n_draws=1000, n_trials=None, seed=0, unit='trials')[source]#

Resample one phase’s trials (or sessions) and recompute its statistics.

Delegates to resample_stat_vectors(), the library’s single resample-and-recompute engine, so the frozen lag-1 prev_* pairing survives every draw (a repeated trial carries its own predecessor).

unit='trials' (default) is a per-trial bootstrap, stratified by stimulus bin, and answers “how precisely is this phase’s stat pinned by its trials”. unit='sessions' resamples whole sessions with replacement instead: it treats the session as the independent unit, so the interval reflects session-to-session scatter (the right unit when the phase spans sessions that were not randomised per trial — e.g. an opto phase vs a sham phase). A matched n_trials only applies to the trial bootstrap.

The trial draw is stratified by stimulus bin: the stimulus composition is held roughly fixed across draws because the stimulus set is fixed by the design, so the interval is conditional on it (slightly narrower than an unconditional bootstrap). The session draw is unstratified.

Parameters:

  • phase – list of SessionData from filter_trials.

  • names (Sequence[str]) – scalar stat names. For unit='trials' these must be trial-exchangeable; unit='sessions' accepts any stat.

  • n_draws (int) – number of resamples.

  • n_trials (int | None) – trial bootstrap only — draw this many trials instead of the natural count (a matched n for equal-precision contrasts).

  • seed (int) – RNG seed.

  • unit (str) – ‘trials’ (default) or ‘sessions’.

Returns:

pd.DataFrame (n_draws × names). Failed draws are NaN rows.

Raises:

ValueError – if unit='trials' and any stat is not trial-exchangeable.

Return type:

DataFrame

behav_utils.analysis.permute_phase_difference(phase_a, phase_b, names, *, n_draws=1000, n_trials=None, seed=0)[source]#

Null distribution of stat(a) - stat(b) from shuffling the labels.

Pools both phases, reassigns the phase label at random keeping the group sizes fixed, and recomputes the difference — the null being “which phase a trial belongs to carries no information”.

Only use this where the label really was randomised per trial. Opto vs non-opto within a phase qualifies (the rig interleaved it). Comparing phases that differ by session type does not: those trials were collected on different days, so a shuffle would treat non-exchangeable trials as exchangeable and absorb every between-day difference into the null. Use bootstrap_phase_stats() and an interval there instead.

Parameters:

  • phase_a – the two phases; the difference is a - b.

  • phase_b – the two phases; the difference is a - b.

  • names (Sequence[str]) – scalar stat names.

  • n_draws (int) – number of shuffles. The smallest reportable p is 1 / (n_draws + 1).

  • n_trials (int | None) – draw this many per side instead of the natural counts.

  • seed (int) – RNG seed.

Returns:

pd.DataFrame (n_draws × names) of differences under the null. A shuffle that produced an unfittable split is a NaN row; summarise_draws drops NaNs rather than counting them as zero.

Raises:

ValueError – the phases share trials (shared_trial_count > 0).

Return type:

DataFrame

How many trials two phases have in common (same session_id and trial_number).

Two phases cut from the same sessions overlap when one trial class contains the other, e.g. post_opto trials are also non_opto trials. A contrast between overlapping phases is diluted (the shared trials sit on both sides), and a permutation cannot give one trial two labels, so permute_phase_difference refuses them and compute_delta_stat refuses or warns.

behav_utils.analysis.summarise_draws(draws, *, observed=None, ci=0.95, null_value=0.0)[source]#

Percentile interval and two-sided p from a distribution of draws.

Works for either engine, but the p means different things:

  • bootstrap draws (of a difference) — p is the proportion of draws on the far side of null_value, doubled. Report observed as the estimate and the interval as its uncertainty.

  • permutation draws — pass observed (the unshuffled difference) and p becomes the proper permutation p-value, (1 + #{|draw| >= |observed|}) / (n + 1). The +1 keeps it from ever being exactly zero; the floor is 1 / (n + 1).

Do not compare two intervals by eye to judge a difference. Two 95% intervals can overlap while the difference is significant. Build the difference distribution and summarise that instead.

Parameters:

  • draws – 1-D array-like of resampled values (a DataFrame column). NaNs dropped.

  • observed (float | None) – the unshuffled statistic — required for a permutation p.

  • ci (float) – interval mass, e.g. 0.95.

  • null_value (float) – value corresponding to “no effect”.

Returns:

DrawSummary; all NaN (except n_draws) if fewer than 10 usable draws.

Return type:

DrawSummary

Source: percentile bootstrap intervals (Efron & Tibshirani, 1993); the permutation p with one added to the count and to the number of permutations (Phipson & Smyth, 2010); the docs site lists the references.

behav_utils.analysis.downsample(clean, n, unit='trials', with_replacement=True, n_bins=8, rng=None)[source]#

Subsample clean sessions to ~n of the chosen unit; returns new [SessionData].

The matched-n draw is pooled across sessions (frozen prev_* make this safe), then split back per session and rebuilt, so the output is consumable by compute_psychometric_curve / compute_update_matrix unchanged. with_replacement=True allows a trial to be drawn more than once (a bootstrap resample); False is a clean subsample.

behav_utils.analysis.resample_stat_vectors(clean, stat_names, *, n=None, n_repeats=1000, with_replacement=True, unit='trials', seed=0)[source]#

Resample trials K times and recompute summary stats — one matrix of replicates.

The single resample-and-recompute engine for scalar stats. It is the scalar analogue of resample_psychometric_curve() / resample_update_matrix() (which target the readouts), and serves BOTH uses via its arguments:

  • trial bootstrap — with_replacement=True, n=None (natural count)

  • matched-n draw — with_replacement=False, n=target_n

Drawing is delegated to downsample(), so the frozen lag-1 prev_* pairing is preserved on every resample (a repeated trial index carries its own predecessor). Stats registered exchangeable=False are refused: trial resampling is invalid for order-dependent stats and would return a confidently-wrong interval.

Parameters:

  • clean – list of [SessionData], abort/opto-cleared (a phase/condition).

  • stat_names – scalar stat names (list_stats()).

  • n – trials/pairs to draw per repeat; None → the natural count of unit in clean (the right default for a bootstrap).

  • n_repeats – number of resamples (rows of the returned matrix).

  • with_replacement – True for a bootstrap resample, False for a clean subsample.

  • unit – ‘trials’ (responded trials), ‘pairs’ (post-correct pairs), or ‘sessions’ (whole sessions, drawn intact — valid for order-dependent stats; natural n = n_sessions).

  • seed – RNG seed.

Returns:

pd.DataFrame of shape (n_repeats, len(stat_names)), columns in request order. Rows where the draw was empty are NaN.

Raises:

ValueError – if any requested stat is not trial-exchangeable.

behav_utils.analysis.compare_groups(rows, group_col='group', groups=None, stats=None, value_col='value', stat_col='stat', unit_col='animal', paired=False, alternative='two-sided')[source]#

Rank-test each stat across animals, split into two groups.

One test per stat: one value per animal (rows of the same animal within a group are averaged), split into the two groups, rank-test. Animals with a non-finite value for a stat are dropped from that stat’s test only.

Grouping is specified one of two ways:

  • by column — group_col names a column already on the rows (the default, ‘group’);

  • by name-lists — groups={label: [animal, ...]} assigns each animal to a group explicitly, needing no group column. Use this for an ad-hoc split.

Parameters:

  • rows (DataFrame | Sequence[Mapping[str, Any]]) – list of dicts, or a DataFrame — accumulated collect_rows output across animals.

  • group_col (str) – column holding the grouping (ignored if groups given).

  • groups (Sequence[str] | Mapping[str, Sequence[str]] | None) – either the two group labels in (a, b) order (selecting from group_col), or a {label: [animal_ids]} mapping that defines the split directly. If None, the two labels present in group_col are used in sorted order — pass the pair explicitly whenever the reference group matters.

  • stats (Sequence[str] | None) – which stats to test; default is every stat present.

  • value_col (str) – The column holding the values.

  • stat_col (str) – The column holding each value’s statistic name.

  • unit_col (str) – The column identifying the unit, usually the animal, a value belongs to.

  • paired (bool) – Wilcoxon signed-rank instead of Mann-Whitney. The two “groups” are then two conditions of the same animals: the values are aligned by unit_col and an animal missing a finite value on either side is dropped from that pair.

  • alternative (str) – ‘two-sided’ | ‘less’ | ‘greater’.

Returns:

GroupComparison — .test(stat) is a RankTest whose min_p is the smallest p obtainable at these group sizes; compare a p against it before reading a null as no effect. .table() is tidy.

Raises:

ValueError – on no rows, fewer than two groups, a name-list mapping without exactly two groups, or paired=True with disjoint animals.

Return type:

Collapse one axis of a tidy stat table, carrying all other label columns.

Groups by every column except over and the value/weight/CI columns, so it can never silently average across conditions, phases, stats or groups.

  • over='session' → one value per (animal, stat, label…) — per-animal.

This is the average path. The trial-weighted alternative (re-pool trials, compute once) comes from compute_phase_stats(...).to_rows() instead — a deliberately different number. Within-unit CIs are dropped on output because they no longer apply; a group CI comes from bootstrap_units().

behav_utils.analysis.min_achievable_p(test, *, n=None, n1=None, n2=None)[source]#

Smallest two-sided p-value the given rank test can return at this sample size.

Rank tests are discrete: with few observations even a perfectly consistent effect cannot drop below a floor set by the number of possible rank arrangements. Report this beside a non-significant result to show whether the test could have rejected at all — a p that merely equals this floor is the strongest evidence the sample can give, not a meaningful null.

Parameters:

  • test – ‘signed_rank’ (Wilcoxon signed-rank / paired) — needs n, the number of non-zero pairs; floor = 2 / 2**n (all pairs the same sign). ‘rank_sum’ (Mann-Whitney U / unpaired) — needs n1, n2; floor = 2 / C(n1 + n2, n1) (the most extreme rank separation).

  • n – non-zero pair count for ‘signed_rank’.

  • n1 – group sizes for ‘rank_sum’.

  • n2 – group sizes for ‘rank_sum’.

Returns:

Minimum two-sided p in (0, 1], or nan if sizes are missing / too small.

Assumes the exact (permutation) null and no ties; scipy uses the exact distribution at these small n, so the floor matches what rank_test() can actually return.
