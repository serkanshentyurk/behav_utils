behav_utils.readouts#

Array-valued readouts of a block of trials (see _base for the contract).

Each compute_x(arrays) returns a frozen dataclass with one draw-only plotter: for example compute_update_matrix(arrays) gives an UpdateMatrix, with .matrix, .profile() and .to_rows().

The fit engines on raw arrays (fit_psychometric, fit_update_matrix) live in fit.py; stats and the readouts both import them, and fit.py imports nothing from the package.

behav_utils.readouts.fit_psychometric(stimuli, choices, x_eval=None, n_bootstrap=0, seed=42)[source]#

Fit psychometric curve to choice data.

Parameters:

  • stimuli (ndarray) – Array of stimulus values

  • choices (ndarray) – Array of binary choices (0 = A, 1 = B)

  • x_eval (ndarray | None) – Points at which to evaluate fitted curve (default: linspace(-1, 1, 100))

  • n_bootstrap (int) – Number of bootstrap samples for confidence intervals (0 = no bootstrap)

  • seed (int) – Random seed for bootstrap

Returns:

A dict with these keys:

'mu'          PSE (point of subjective equality)
'sigma'       Slope (smaller = steeper)
'lapse_low'   Lower lapse rate (floor)
'lapse_high'  Upper lapse rate (1 - ceiling)
'x_fit'       Evaluation points
'y_fit'       Fitted curve values
'nll'         Negative log-likelihood
'success'     Whether fit succeeded

With n_bootstrap > 0, also:

'mu_ci'             (lower, upper) 95% CI for mu
'sigma_ci'          (lower, upper) 95% CI for sigma
'lapse_low_ci'      (lower, upper) 95% CI for lapse_low
'lapse_high_ci'     (lower, upper) 95% CI for lapse_high
'y_fit_ci'          (lower, upper) curves for the 95% CI band
'bootstrap_params'  DataFrame with all bootstrap parameter values

Return type:

Dict

Source: the form with lapse rates and the constrained maximum-likelihood fit follow Wichmann & Hill (2001); the docs site lists the references.

behav_utils.readouts.fit_update_matrix(stimuli, choices, *, correct, n_bins=8, trial_filter='post_correct', no_response=None, not_blockstart=None, prev_stimuli=None, prev_choices=None, prev_correct=None)[source]#

Compute update matrix from raw behavioural arrays.

The update matrix captures serial dependence: how does the previous trial’s stimulus shift the current psychometric curve?

Parameters:

  • stimuli (ndarray) – Stimulus values for each trial.

  • choices (ndarray) – Binary choices (0=A, 1=B).

  • correct (ndarray) – The task’s score per trial (TrialArrays.correct): 1 correct, 0 error, NaN no score. Keyword-only: the engine never decides correctness itself.

  • n_bins (int) – Number of bins for stimulus discretisation.

  • trial_filter (Literal['all', 'post_correct']) – ‘post_correct’ (only after correct) or ‘all’.

  • no_response (ndarray | None) – Bool array (True = no response). Inferred from NaN if None.

  • not_blockstart (ndarray | None) – Bool array (True = not start of block). Auto if None.

  • prev_stimuli (ndarray | None) – Frozen, abort-aware lag-1 arrays aligned to every trial. If prev_stimuli is given, the previous trial is taken from these (NOT from array adjacency), so the matrix is correct on a non-consecutive subset (e.g. opto-only or post-opto trials). If None, the previous trial is the immediately preceding array element via not_blockstart (the simulated / SBI path, unchanged).

  • prev_choices (ndarray | None) – Frozen, abort-aware lag-1 arrays aligned to every trial. If prev_stimuli is given, the previous trial is taken from these (NOT from array adjacency), so the matrix is correct on a non-consecutive subset (e.g. opto-only or post-opto trials). If None, the previous trial is the immediately preceding array element via not_blockstart (the simulated / SBI path, unchanged).

  • prev_correct (ndarray | None) – Frozen, abort-aware lag-1 arrays aligned to every trial. If prev_stimuli is given, the previous trial is taken from these (NOT from array adjacency), so the matrix is correct on a non-consecutive subset (e.g. opto-only or post-opto trials). If None, the previous trial is the immediately preceding array element via not_blockstart (the simulated / SBI path, unchanged).

Returns:

update_matrix – (n_bins, n_bins) shift in P(B) conditional_matrix: (n_bins, n_bins) conditional P(B) values info: Dict with fitting details

Return type:

Tuple[ndarray, ndarray, Dict]

class behav_utils.readouts.UpdateMatrix(matrix, conditional, unconditional, n_pairs, n_trials, trial_filter, n_sources=1, coverage=None, sem=None)[source]#

(n_bins × n_bins) shift in P(B). Row = current-stimulus bin, column = previous-stimulus bin.

matrix[i, j] = P(B | cur bin i, prev bin j) − P(B | cur bin i), from a per-previous-bin cumulative-Gaussian fit minus the unconditional fit, both evaluated at the bin centres. NaN columns had fewer than MIN_PAIRS_PER_BIN pairs or a failed fit.

behav_utils.readouts.compute_update_matrix(arrays, *, n_bins=8, trial_filter='post_correct')[source]#

Update matrix on one block of trials, using the frozen lag-1 view.

Parameters:

  • arrays (TrialArrays) – Pre-filtered trials of one block. They may be a non-consecutive subset, such as the opto trials only: each trial’s predecessor comes from the prev_* arrays, never from its neighbour in the arrays.

  • n_bins (int) – Stimulus bins on the fixed [-1, 1] grid.

  • trial_filter (Literal['post_correct', 'all']) – ‘post_correct’ keeps the pairs whose previous trial was correct; ‘all’ keeps every responded pair.

Returns:

An UpdateMatrix. A previous-stimulus bin with fewer than 10 pairs, or whose fit fails, stays NaN.

Raises:

RequirementError – The task is not binary or has no stimulus axis.

Return type:

UpdateMatrix

Source: the updating analysis of Lak et al. (2020). Each conditional curve here is a maximum-likelihood fit to single trials; the docs site lists the references.

behav_utils.readouts.compute_serial_bias(arrays, *, n_bins=8)[source]#

The serial-bias curve over previous − current stimulus in [-2, 2] on the library’s axis.

The errors are regressed on the difference and on the current stimulus, and the current stimulus’s part, with the intercept, is removed, so central tendency does not show as serial bias. The curve is the mean of what remains per bin of the difference.

Parameters:

  • arrays (TrialArrays) – Pre-filtered trials of one block.

  • n_bins (int) – Bins over the difference between the previous and the current stimulus, [-2, 2].

Returns:

A SerialBiasCurve, with the mean, SEM and count per bin.

Raises:

RequirementError – The task’s responses are not continuous.

Return type:

SerialBiasCurve
