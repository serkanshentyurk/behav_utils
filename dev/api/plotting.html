behav_utils.plotting#

behav_utils.plotting — draw-only plotters.

Every plotter takes a typed result from the matching compute_x function and computes nothing; every one is single-panel and takes ax:

compute_psychometric_curve(arrays)             → plot_psychometric_curve(curve, ax=)
compute_update_matrix(arrays)                  → plot_update_matrix(um, ax=)
compute_conditional_psychometric(arrays)       → plot_conditional_psychometric(cp, ax=)
compute_binned_curve(arrays)                   → plot_binned_curve(bc, ax=)
compute_sd_profile(arrays)                     → plot_sd_profile(sd, ax=)
compute_phase_stats(sessions, per_session=True)→ plot_trajectory(result, stat, ax=)
compute_rolling_stats(sessions, names)         → plot_rolling_stats(result, stat, ax=)
compute_delta_stat({...})                      → plot_psychometric_comparison(d, ax=) / plot_stat_comparison(d, stat, ax=)
compute_interaction(r1, r2, key)               → plot_interaction(ix, stat, ax=)

Layout is the caller’s: pass ax. Overlay by calling the same plotter twice on one axes with different colours. The only exception: plot_stat_comparison_grid and plot_interaction_grid build a grid of axes and call the single-panel plotter once per stat.

behav_utils.plotting.plot_stat_comparison(result, stat, ax=None, *, phase_order=None, palette=None, show_p=True, units=None)[source]#

One stat: a point per phase with its bootstrap CI(s); p above each non-reference phase.

The point is the pooled estimate and the interval its sampling uncertainty (not a session spread). units selects which intervals to draw (default: the result’s primary unit only). Above a non-reference phase the permutation p is shown when present; otherwise the bootstrap p per unit (pt trials, ps sessions).

behav_utils.plotting.get_colour(index_or_name)[source]#

Resolve a colour from index (int) or name (str).

Usage:

get_colour(0) → PALETTE[0] (blue) get_colour(‘BE’) → COLOURS[‘BE’] (steelblue) get_colour(‘#ff0000’) → ‘#ff0000’ (passthrough)

Constants#

PALETTE is the list of colours the plotters cycle through, COLOURS gives the colour for a named role (correct, error, no_response, mean_line, sem_fill, default), and UM_CMAP is the colour map for update matrices.
