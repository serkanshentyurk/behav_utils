behav_utils.models#

behav_utils.models — behavioural models and simulation.

A model is anything with simulate(design, rng) -> Responses; a Design is a run without its responses (task, stimuli, laser, abort and no-response flags), drawn by make_design. simulate(model, design) returns a SessionData scored by the task, so synthetic data goes through the same statistics as real data; simulate_responses returns only the choices.

TrialwiseModel runs the trial loop for models that learn (write p_choice or respond, and update, each taking a TrialInfo); IdealObserver and normative_pse give the Bayesian benchmark for a stimulus distribution. generate_synthetic_session / _animal / _experiment produce synthetic data with every trial class and event times, from the built-in PsychometricModel or any model.

class behav_utils.models.Model[source]#

A behavioural model: simulate(design, rng) returns its Responses to a run.

Anything with that method works with simulate(); subclassing is optional. A model may look at the whole design, the laser flags included. simulate() blanks aborted and no-response trials afterwards, whatever the model returns for them. requires names the task capabilities the model needs (as statistics do); simulate() refuses a design whose task lacks them.

class behav_utils.models.TrialwiseModel[source]#

A model that responds trial by trial and may learn from feedback.

A binary model writes p_choice(trial), the probability of response 1; any other writes respond(trial, rng), which returns the response itself. update(trial) (learning) and reset() (the start of a run) are optional. simulate calls reset(), then, for each trial that is neither aborted nor a no-response, asks for a response and calls update with the trial completed: its choice, the task’s score of it and the truth (TrialInfo).

class behav_utils.models.PsychometricModel(mu=0.0, sigma=0.3, lapse_low=0.02, lapse_high=0.02, laser=None)[source]#

Choices from the psychometric curve the library fits (fit_psychometric).

P(response 1 | s) = lapse_low + (1 - lapse_low - lapse_high) * Phi((s - mu) / sigma). Simulate, then fit, and the parameters come back.

Variables:

  • mu (float) – The point of subjective equality, on the library’s axis.

  • sigma (float) – The cumulative Gaussian’s SD; smaller is steeper.

  • lapse_low (float) – The lower asymptote.

  • lapse_high (float) – One minus the upper asymptote.

  • laser (Mapping[str, float] | None) – Values used instead of the model’s own on laser trials, {parameter: value}; None for none. A name the model does not have is refused with a ValueError.

Parameters:

  • mu (float)

  • sigma (float)

  • lapse_high (float)

class behav_utils.models.IdealObserver(noise=0.3, distribution=<factory>, lapse=0.0, laser=None)[source]#

The Bayesian observer, with Gaussian sensory noise and a prior of its own.

It perceives each stimulus with Gaussian noise (sd noise) and, under its prior distribution and the design’s task, gives the response whose category has the higher posterior (a binary task with a stimulus axis), or its posterior mean of the stimulus (a continuous task, which pulls responses towards the middle: see normative_slope). With probability lapse it responds at random. Its prior can differ from the distribution the design draws from.

Variables:

  • noise (float) – SD of the Gaussian noise on each perceived stimulus, on the library’s axis.

  • distribution (behav_utils.tasks.distributions.StimulusDistribution) – Its prior over stimuli; Uniform() by default.

  • lapse (float) – Probability of a random response.

  • laser (Mapping[str, float] | None) – Values of noise or lapse used instead on laser trials, {parameter: value}; None for none. Any other name is refused with a ValueError.

Parameters:

  • noise (float)

  • distribution (StimulusDistribution)

  • lapse (float)

  • laser (Mapping[str, float] | None)

behav_utils.models.normative_pse(distribution, noise, task=None)[source]#

The ideal observer’s point of subjective equality: the percept at which both categories are equally probable under distribution with sensory noise noise. With a likelihood that rises with the stimulus, the observer answers 1 above it, so it is also the PSE a psychometric fit to its choices estimates. NaN, with a warning, if no such point lies near the support.

Parameters:

  • noise (float)

  • task (Task | None)

Return type:

behav_utils.models.normative_slope(distribution, noise)[source]#

The ideal observer’s expected response slope on a continuous task: the least-squares slope of its posterior-mean response on the stimulus, stimuli drawn from distribution (also its prior) and percepts carrying Gaussian noise of sd noise. Below 1 is the pull towards the middle a Bayesian observer shows; for a Gaussian prior of sd s it is s² / (s² + noise²).

Parameters:

  • distribution (StimulusDistribution)

  • noise (float)

Return type:

float

class behav_utils.models.ReproductionModel(bias=0.0, slope=1.0, noise=0.1, lapse=0.0, laser=None)[source]#

A reproducer whose response is a linear function of the stimulus, plus noise.

response = slope * stimulus + bias plus Gaussian noise (sd noise), clipped to the axis [-1, 1]; with probability lapse the response is a uniformly random location instead. A slope below 1 pulls responses towards the middle. Simulate, then compute response_bias, response_slope and error_sd, and they come back.

Variables:

  • bias (float) – Added to every response.

  • slope (float) – How the response scales with the stimulus.

  • noise (float) – SD of the Gaussian noise on the response.

  • lapse (float) – Probability of a uniformly random response.

  • laser (Mapping[str, float] | None) – Values of any of the four used instead on laser trials, {parameter: value}; None for none. A name the model does not have is refused with a ValueError.

Parameters:

  • bias (float)

  • slope (float)

  • noise (float)

  • lapse (float)

  • laser (Mapping[str, float] | None)

class behav_utils.models.Timing(session_start=32400.0, stimulus_delay=0.5, rt_median=0.45, rt_sigma=0.35, response_window=2.0, abort_after=0.2, iti=2.0)[source]#

How a synthetic trial unfolds, in seconds. The session starts session_start after midnight. Each trial presents the stimulus stimulus_delay after it starts; a response follows after the reaction time (lognormal with median rt_median and log-sd rt_sigma, unless the model gives its own), a trial without one waits out response_window, and an abort ends abort_after after the stimulus. The next trial starts iti later.
